# Filtro de eco na transcrição

Numa consulta online, a voz do paciente volta pelo microfone e o Whisper a transcreve como fala da terapeuta. Esta página mostra a transcrição antes e depois de um filtro entre canais: o erro (WER) cai de 125,4% para 1,6%.

Os resultados foram calculados antes, com voz sintética e eco simulado. A página não roda o modelo.

Código, dados e artigo: https://github.com/GusHermeto/portfolio-ia/tree/main/avaliacao-transcricao
